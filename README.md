## 📝 Description

AfriTalent est une plateforme fictive de mise en relation entre freelances tech et entreprises en Afrique. Le site présente la plateforme, ses fonctionnalités, ses tarifs et des profils de freelances. Il vise à convaincre les visiteurs — qu'ils soient freelances ou entreprises — de s'inscrire et de rejoindre la communauté AfriTalent.

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique et accessible
- **CSS3** — Variables CSS, Flexbox, Grid, Bento Grid, animations et media queries
- **Bootstrap 5** — Navbar, cards, carousel, accordion
- **JavaScript (Vanilla)** — Manipulation du DOM, IntersectionObserver, localStorage
- **Bootstrap Icons** — Icônes utilisées sur l'ensemble du site
- **Google Fonts** — Playfair Display et DM Sans
- **Git & GitHub** — Versioning et déploiement via GitHub Pages

---

## ✨ Fonctionnalités principales

- Mode sombre / clair avec sauvegarde de la préférence (localStorage)
- Navbar dynamique qui change de style au défilement
- Compteurs animés au scroll (statistiques)
- Animations en fondu (fade-in) des sections au scroll
- Filtrage dynamique des profils freelances par catégorie
- Validation complète du formulaire de contact (regex email, longueur minimale du message)
- Bouton "Retour en haut" avec défilement fluide
- Design responsive : mobile (375px), tablette (768px), desktop (1200px+)

## 💻 Lancer le projet en local

1. Clonez le dépôt :
   ```
   git clone https://github.com/fasagna13/SAGNA-FATOU-AfriTalent.git
   ```

2. Ouvrez le dossier du projet
3. Double-cliquez sur `index.html` pour l'ouvrir dans votre navigateur

Aucune installation supplémentaire n'est nécessaire — le projet utilise uniquement Bootstrap via CDN.
